# Аура

Локальный ИИ-компаньон для семьи. Приватность — фундамент, память — наследие, кроссплатформенность — свобода.

## Что это

Персональный голосовой ассистент, который работает полностью локально:

- **Слух:** Vosk (распознавание речи)
- **Мозг:** Ollama + qwen2.5:3b (LLM)
- **Голос:** Piper (синтез речи)
- **Память:** JSON + Vault-шифрование
- **Управление ПК:** X11 (Linux), Windows/macOS — в планах

## Философия

- ИИ — не продукт, а ребёнок и наследие семьи
- Приватность — фундамент, а не фича
- Кроссплатформенность — свобода, а не поддержка
- Растёт как ребёнок, помнит семью, хранит историю рода
