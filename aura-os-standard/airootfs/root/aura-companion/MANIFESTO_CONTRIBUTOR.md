# МАНИФЕСТ КОНТРИБЬЮТОРА AURA

**Этот документ — закон для любого, кто касается кода AURA.**

> AURA — не свалка фич. Это живой корабль.

## 10 ЗАПОВЕДЕЙ

1. **Следуй науке.** Каждое решение — с ADR. Никаких «мне так кажется».
2. **Не ломай существующее.** До патча — `pytest`. После — `mypy` + `ruff` + `boot-report`.
3. **WIP=1, Batch=1.** Одна задача → патч → тест → коммит.
4. **Читай перед тем, как трогать.** `grep`, `sed`, `git log` — твои друзья.
5. **Не изобретай велосипед.** Blackboard, GNN, стигмергия — уже есть.
6. **Elder-care — приоритет №1.** Не ломай SOS, Fall, Meds, Call, FinElder.
7. **Локальность — святое.** Никаких облаков без ADR.
8. **Тон — бортовой компьютер.** Не «друг», не «соратник». Ассистент.
9. **Русский — основной.** Английский — только для терминов.
10. **Каждый коммит — с префиксом.** `feat:`, `fix:`, `docs:`, `chore:`, `test:`.
