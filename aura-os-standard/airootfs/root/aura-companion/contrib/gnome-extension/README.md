# Aura GNOME Extension

Статус-индикатор Aura в GNOME Shell.

## Установка
mkdir -p ~/.local/share/gnome-shell/extensions/aura@pythonvenom.local
cp -r contrib/gnome-extension/* ~/.local/share/gnome-shell/extensions/aura@pythonvenom.local/
gnome-extensions enable aura@pythonvenom.local

Требует Aura HTTP API (localhost:8765).
