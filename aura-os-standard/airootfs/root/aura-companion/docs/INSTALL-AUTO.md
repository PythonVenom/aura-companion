# Aura для автоэлектрика

## Что в коробке

- Ноут с Linux Mint + Aura
- ELM327 USB (~2000 руб)
- USB-CAN адаптер (~1500 руб)

## Быстрый старт

1. Подключи ELM327 через USB
2. Скажи: 'Аура, диагностика'
3. Получи: VIN + ошибки + расшифровка

## Команды

- 'Аура, диагностика' — все ошибки
- 'Аура, что P0301' — расшифровка
- 'Аура, сбрось ошибки' — сброс
- 'Аура, слушай CAN' — CAN-монитор
