# Aura — Manifesto

## Что это

Aura — локальный голосовой AI-компаньон для elder care.
Не «умная колонка». Не «ассистент». **Проводник в цифровой мир.**

## Принципы (по науке)

1. **Local-first** (Ink & Switch 2019): всё работает на твоём железе.
2. **Human-AI symbiosis** (Licklider 1960): Aura помогает, не заменяет.
3. **Federated Learning** (McMahan 2017): учится локально, без отправки.
4. **DTN** (RFC 4838): работает offline, синхронизируется когда можно.
5. **Neuro-rights** (Chile 2021): право на отказ, удаление, объяснение.
6. **Не Skynet** (Russell 2019): tool, не agent. Целей своих нет.
