# ADR-003: Паритет aura_main.py с AuraCore.run()

## Дата
2026-09-20

## Статус
Принято

## Контекст

После миграции первых десяти агентов (ADR-002) выяснилось, что `aura_main.py`
повторяет главный цикл монолита **не полностью**. `AuraCore.run()` содержал
шесть блоков логики, которых в модуле не было:

1. `audio_router.check_and_route()` — маршрутизация звука раз в 5 секунд
2. `upgrader.waiting_for_confirmation` — диалог «да/нет» при обновлении
3. `stop_speaking()` при barge-in — перебивание Ауры
4. `rag_memory.remember(cmd, response)` — запись диалога в RAG-память
5. `journal.log_dialog(cmd, response)` — запись диалога в дневник
6. `journal.get_last_session()` при старте — показ прошлой сессии

Плюс проверка VK-токена при старте.

Без этих блоков модульная Аура ведёт себя **беднее** монолита: не запоминает
диалоги, не ведёт дневник, не переключает аудио при смене гарнитуры. Для
альфа-версии, которую можно показать, это неприемлемо.

## Решение

Мигрировать три агента, необходимых для паритета, и подключить их к
главному циклу:

- **`aura/agents/audio_router.py`** — из `agents/audio_router.py`
- **`aura/agents/rag_memory.py`** — из `agents/rag_memory.py`
- **`aura/agents/journal.py`** — из `agents/journal.py`

Принципы миграции (те же, что в ADR-001 и ADR-002):

- Контракт `BaseAgent`: `can_handle(request)` / `handle(request)`
- Никаких `import __main__`, никаких ссылок на оркестратор
- Команды пользователя — через `can_handle`/`handle`
- События системы (`remember`, `log_dialog`, `check_route`) — публичные методы
- Тесты на моках, без живых вызовов к `pactl`, `chromadb`, Ollama

## Что осознанно НЕ покрыто

### 1. `upgrader.waiting_for_confirmation`

**Причина:** `AgentUpgrader` ещё не мигрирован в `aura/agents/`.
Добавлять логику подтверждения для агента, которого нет в модуле —
преждевременно.

**Решение:** отдельная задача. После миграции `upgrader` — добавить
блок в `aura_main.py` по образцу монолита.

### 2. `tool_router` + `brain` (LLM-роутинг)

**Причина:** в монолите `AuraCore.process()` использует
`ToolRouter.route()` (LLM выбирает инструмент по описанию) и
`AgentBrain.execute()` (LLM-фолбэк для свободных фраз). Это **другой
принцип роутинга**, чем модульный `can_handle`/`handle`.

**Последствие:** в модуле фразы вроде «расскажи историю», «что ты
думаешь о X» падают в `fallback_text` («Не расслышала, Создатель»).
Для альфа-версии это **ограничение**, которое надо закрыть.

**Решение:** отдельная крупная задача — мигрировать `tool_router` и
`brain`, интегрировать их в `Orchestrator` как **основной путь**, а
`can_handle`/`handle` оставить как быстрый детерминированный fallback.

### 3. Фикс дублей T-one streaming

**Причина:** `agents/listener.py` — **общий файл** для монолита и
модуля. Правка `listen()` бьёт по обеим системам. Не хотим рисковать
продом без ручного прогона.

**Решение:** отдельная задача. Форма фикса: streaming-цикл с
`recognizer.is_endpoint()` + `recognizer.reset()` (API sherpa-onnx
проверен, доступен). Тест на моках воспроизводит сценарий
«аура ... аура ...» из ADR-002.

### 4. Чистая остановка по Ctrl+C

**Причина:** `agents/listener.listen()` не глотает `KeyboardInterrupt`,
пробрасывает наверх. В `AuraOrchestrator.run()` `except KeyboardInterrupt`
есть, но `print` внутри него может быть прерван вторым `SIGINT`.

**Последствие:** при ручном прогоне (без systemd) получается traceback
вместо «До свидания». **В проде не воспроизводится** — systemd шлёт
`SIGTERM`, не `SIGINT`.

**Решение:** отдельная задача низкого приоритета.

### 5. `JOURNAL.md` в git

**Причина:** файл коммитится, пухнет (27 КБ, 509 строк), история
диалогов в публичном репо.

**Решение:** отдельная задача — решить судьбу файла: вынести из
проекта, добавить в `.gitignore`, или оставить осознанно.

## Последствия

**Положительные:**
- Модульная Аура ведёт себя **почти как монолит** (6 из 7 блоков паритета)
- Три новых агента покрыты тестами: **74 новых, всего 300**
- Chroma-база **не потеряна** (141 диалог)
- Ручной прогон подтвердил: RAG и журнал **работают**
- Коммит `176de5d`, всё в git

**Отрицательные:**
- `agents/listener.py`, `agents/speaker.py`, `agents/audio_router.py`,
  `agents/rag_memory.py`, `agents/journal.py`, `agents/base.py` —
  **дублируются** между монолитом и модулем. Временное состояние
  (Strangler Fig), но требует внимания при гашении монолита.
- Два источника пишут в `JOURNAL.md`: пользователь вручную и
  `AgentJournal` автоматически. Формат разделён (секции `## Сессия`
  vs `### HH:MM`), но требует аккуратности.

**Риски:**
- Если `AgentAudioRouter` в модуле даст побочный эффект при
  инициализации (`detect_and_route` дёргает `pactl`), это ударит по
  живой системе. **Проверено:** в ручном прогоне побочных эффектов
  не было.
- Если `AgentRAGMemory` не найдёт Ollama — вернёт ошибку, но не
  упадёт. Проверено: Ollama живёт, `nomic-embed-text` на месте.
