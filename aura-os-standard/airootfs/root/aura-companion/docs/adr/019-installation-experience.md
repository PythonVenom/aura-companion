# ADR-019: Installation Experience

**Дата:** 2026-09-28
**Статус:** Принято

## Контекст

Порог входа для не-технических пользователей (бабушки, незрячие, моторные ограничения) — критичен. Сейчас установка требует:
- Arch Linux
- Терминал
- Понимание `pacman`, `systemd --user`, Python

Это **недопустимо** для миссии.

## Решение

**Три уровня установки:**

### Уровень 1 — Flash-install (для бабушек)
- Образ Arch + Аура на флешке (`.iso`, ~2.5 ГБ)
- Загрузка с флешки
- `install-aura.sh` — автоматически ставит на диск
- Два вопроса: «Стереть диск? [y/N]», «Имя ассистента? [Аура]»

### Уровень 2 — Скрипт (для разработчиков)
- Текущий `install.sh` + `aura/system_check.py` в начале
- Pre-check показывает что работает
- Post-report показывает что установлено

### Уровень 3 — Ручная (для экспертов)
- `pip install -e .` + настройка systemd
- Документация в `docs/install-advanced.md`

## Реализация

### Pre-check (`aura/system_check.py`)
- CPU, RAM, GPU, аудио
- Оценка «потянет LLM?»
- Цветной отчёт в терминале
- Пользователь видит **что будет работать** до установки

### Post-report (`aura/install_report.py`)
- Что установлено (venv, T-one, Piper, Ollama, VLC, Firefox)
- Что работает, что нет
- Рекомендации

### Flash-образ (позже, отдельная задача)
- `mkarchiso` конфиг
- `make_flash_image.sh`
- Auto-install скрипт

## Последствия

**Плюсы:**
- Бабушка может установить сама
- Прозрачность (знает что будет работать)
- Recovery при ошибках (что не хватает — говорит)

**Минусы:**
- Поддержка двух режимов установки
- Flash-образ = 2.5 ГБ
