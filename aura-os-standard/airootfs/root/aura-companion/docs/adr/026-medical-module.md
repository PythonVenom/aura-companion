# ADR-026: Medical Module

**Дата:** 2026-09-28
**Статус:** Проект

## Контекст

Врачи, массажисты, иглоукалыватели, неврологи работают руками.
Записи ведут голосом. Данные — медицинская тайна (152-ФЗ).

## Решение (проект)

**Aura Medical** — отдельный реестр агентов для клиник.
Локально, без облака.

### Агенты

- **MedicalHistoryAgent** — RAG по истории пациента
- **SessionTimerAgent** — сессия 40/50/60 мин
- **ProgressTracker** — динамика симптомов
- **DictationAgent** — диктовка жалоб/наблюдений
- **MedicalVault** — шифрованное хранилище (age/GPG)

### Сценарий

1. Врач: «Аура, пациент Иванов, 45 лет, головная боль»
2. Аура: пишет в RAG
3. Врач: «Что было в прошлый раз?»
4. Аура: «7/10, сейчас?»
5. Врач: «3/10, улучшение»
6. Через 10 сеансов — отчёт

### Юридически

- **152-ФЗ** — медицинские данные
- Локально → **данные не утекут**
- Шифрование: `age` или GPG
- Согласие пациента обязательно

### Что НЕ делаем

- Диагнозы (Аура не врач)
- Лечение (только фиксация)
- Облако (только локально)
