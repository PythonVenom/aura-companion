# ADR-028: Licensing Strategy

**Дата:** 2026-09-28
**Статус:** Принято

## Контекст

Открытый код на GitHub. Риск: форкнут, продадут без отчислений.

## Решение

**Гибридная стратегия.**

### Уровень 1: Код

**MIT** (сейчас):
- Открывает двери, зовёт звёзды
- Позволяет форки и коммерческое использование
- Защита: репутация + бренд

### Уровень 2: Бренд

**Товарный знак** по классам МКТУ:
- **09** — ПО
- **42** — IT-услуги

Регистрация: Роспатент, 30–50k ₽, 6–12 мес.

Форки могут использовать код, **но не имя**.

### Уровень 3: Коробка (позже)

Отдельный ТЗ на «Aura Box» / «Проводница» — когда будет продукт.

### Если пойдёт коммерция

Переход на **BSL-1.1**:
- Коммерческое использование — по лицензии
- Через 4 года → MIT
- Прецеденты: MariaDB, Sentry

### Что НЕ делаем

- Не закрываем код (убьёт сообщество)
- Не GPL-3 (сложнее для B2B)
- Не отзываем MIT задним числом
