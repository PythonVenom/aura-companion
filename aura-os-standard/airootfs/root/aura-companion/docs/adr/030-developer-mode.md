# ADR-030: Developer Mode

**Дата:** 2026-09-28
**Статус:** Проект

## Контекст

Программисты — 10+ млн человек. Работают за ПК 8+ часов.

Нужен режим Ауры для разработки:
- Объяснение кода
- Поиск багов
- Рефакторинг
- Документация
- Тесты

Всё локально — без отправки кода в облако.

## Решение

**Aura Dev** — отдельный реестр агентов.

### Агенты

- **DevExplainAgent** — «объясни этот код»
- **DevFindBugAgent** — «найди баг в файле X»
- **DevRefactorAgent** — «отрефактори функцию Y»
- **DevDocsAgent** — «сгенерируй docstring»
- **DevTestAgent** — «напиши тесты для модуля»

### Интеграция

**Плагины:**
- VSCode (extension API)
- Neovim (Lua + RPC)
- JetBrains (plugin)
- CLI (`aura dev explain file.py`)

### Безопасность

- Код **не отправляется** в облако
- LLM работает локально (qwen2.5-coder)
- Индексация через ripgrep + ChromaDB

### Модели

- **qwen2.5-coder:7b** — основная
- **qwen2.5-coder:32b** — для Strix Halo
- RAG: docs + code + git history

## Последствия

**Плюсы:**
- Новая аудитория (разработчики)
- Потенциальный доход (B2C подписка)
- Портфолио для AMD (кейс code AI)

**Минусы:**
- Отдельный реестр агентов
- Отдельный цикл релизов
- Конкуренция с Copilot (но локально)
