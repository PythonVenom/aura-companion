# ADR-033: Bookkeeping Vertical

**Дата:** 2026-09-28
**Статус:** Проект
**Связано:** strategy-2026.md, ADR-030

## Контекст

5 млн бухгалтеров РФ работают в Excel / LibreOffice / 1С.
Рутина: сводные, поиск расхождений, акты, счета, отчёты.

Copilot в Office = облако → **нельзя** для госсектора, банков, параноидальных CFO.

## Решение

**Aura Bookkeeping** — локальный реестр агентов для таблиц и документов.

### Агенты

- **TableAgent** — «построй сводную по кварталу», pandas/openpyxl
- **ReconcileAgent** — «найди расхождение в актах», diff + LLM
- **InvoiceAgent** — «сгенерируй счёт по шаблону», docx
- **ReportAgent** — «отчёт за месяц», шаблоны + LLM
- **FormulaExplainAgent** — «объясни формулу =ВПР(...)»

### Стек

- **Excel/XLSX:** openpyxl + pandas
- **Word/DOCX:** python-docx
- **LibreOffice:** UNO (headless) для тяжёлых случаев
- **LLM:** qwen2.5:7b (локально)
- **RAG:** ChromaDB по документам пользователя

### Команды (голос + CLI)

- «Аура, открой books.xlsx»
- «Аура, сводная по контрагентам за Q3»
- «Аура, найди расхождения в актах за сентябрь»
- «Аура, сформируй счёт для ООО Ромашка»
- «Аура, экспорт в PDF»

### Интеграции (позже)

- 1С (COM/OData)
- Диадок / СБИС (ЭДО)
- ФНС API (проверка контрагентов)

### Юридически

- Локально = **данные не утекают** (152-ФЗ + коммерческая тайна)
- НЕ даём налоговых советов (как ADR-031)
- Аура **помогает**, бухгалтер **решает**

### Монетизация

- Free: до 100 строк в таблице
- Pro: 990 ₽/мес — unlimited + шаблоны
- Enterprise: 5000 ₽/мес — 1С интеграция + ЭДО

## Последствия

**Плюсы:** новая аудитория (B2B), защита данных = дифференциация
**Минусы:** сложно (парсинг Excel — ад), нужен отдельный UI
