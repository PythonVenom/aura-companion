# ADR-040: Voice Profiles

**Дата:** 2026-09-28
**Статус:** Проект
**Связано:** ADR-023 (Voice Customization), ADR-036 (Craftsman)

## Контекст

110+ профессий → разный контекст общения:
- Хирург: «сестра, скальпель» (кратко, чётко)
- Художник: «добавь охры» (образно)
- Водитель: «пробки на МКАД?» (быстро, громко)
- Ребёнок: «расскажи сказку» (мягко)

## Решение

**Voice Profiles** — предустановленные стили общения.

### Профили

| Профиль | Persona | Rate | Vocab | Контекст |
|---|---|---|---|---|
| `default` | тёплая | 1.0 | обычный | дом, офис |
| `medical` | нейтральная | 1.1 | мед.термины | клиника |
| `craft` | нейтральная | 0.95 | техн.термины | мастерская |
| `drive` | краткая | 1.2 | короткие фразы | руль |
| `kids` | мягкая | 0.85 | упрощённый | дети |
| `dev` | техничная | 1.0 | IT-термины | IDE |
| `accessibility` | терпеливая | 0.9 | развёрнуто | бабушка |

### Применение

- CLI: `aura settings set voice_profile medical`
- Автопереключение: если активен агент из кластера (ADR-036) → профиль кластера
- Per-user: в multi-client (ADR-029) каждый клиент свой профиль

### Формат

В `settings.json`:

    {
      "voice_profile": "default",
      "voice_profiles": {
        "medical": {"rate": 1.1, "vocab": "medical", "style": "neutral"}
      }
    }

### Что НЕ делаем

- Обучать голосовые модели на пользователе (privacy)
- Автопереключение без согласия (YAGNI)
- Клонировать голос умершего (этика, отдельный ADR)
