# ADR-053: Pull-модель обновлений (сервер-кормушка)

**Статус:** Принято (перенесено из VISION-2026-09-30)
**Дата:** 2026-09-30

- Дочь знает адрес сервера. Сама решает, когда идти.
- Пришла → поела → ушла. Следов нет.
- Сервер не логирует. Не знает, кто пришёл. Не хранит IP, User-Agent, timestamp.
- Подпись обновлений приватным ключом. Проверка публичным у дочери.
- Публичный ключ вшит в дочь. Не подделать.
- Минимальный контроль: подписанный запрос от дочери. Без записи в лог.
- Не push. Pull. Stateless на уровне идентичности.
- Юридически: не обрабатываем персональные данные, потому что не знаем, кто пришёл.
- Референсы: WO2001080023A1 (device-initiated upgrade, 2001), fwknop, VSM Protocol.
