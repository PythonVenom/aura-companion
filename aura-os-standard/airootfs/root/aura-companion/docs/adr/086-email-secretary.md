# ADR-086: Email Secretary

**Дата:** 2026-10-02
**Статус:** Проект

## Контекст
Aura = секретарь, не email-клиент. Gmail лучше для UI.

## Решение
IMAP IDLE + LLM-приоритет + голосовой дайджест.
- IMAP SSL напрямую (без Google API)
- Пароли в keyring / ~/.config/aura/email.enc
- LLM классифицирует: срочно / подожди / спам
- Голосом: "3 письма: Иван — смета, банк — оплата, мама — привет"
- Ответ: "ответь Ивану: ок, 14:00"
- Calendar bridge: "встреча 15:00 — добавить?"
- Logbook: "отвечал Ивану 3 дня назад"

## YAGNI
- Свой email-клиент (нет)
- Автоответ без подтверждения (нет)
- Удаление без подтверждения (нет)

## Безопасность
- IMAP только SSL
- Пароли зашифрованы
- Never send/delete без confirm
- Whitelist отправителей (опционально)
