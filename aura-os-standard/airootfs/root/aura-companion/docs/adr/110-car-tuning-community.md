# ADR-110: Авто-сервис + тюнинг + сообщество

**Дата:** 2026-10-12
**Статус:** Проект
**Связано:** ADR-150 (Car-assistant), VISION-AUTO

## Контекст

Автосервис и тюнинг — не один рынок, а три слоя:
1. Диагностика (СТО, гараж) — F-150
2. Тюнинг (энтузиасты) — F-151
3. Сообщество (сеть сервисов) — F-152

Схема с друзьями-сервисменами = канал дистрибуции через доверие.

## Решение

Три слоя последовательно:
- F-150: OBD-II + голос, 12 000 ₽ железо
- F-151: Tuning HUD, +5 000 ₽
- F-152: Community платформа

Монетизация — 4 канала: мастерские, маркетплейс пресетов,
fleet-подписка, data-аналитика.

## Схема с друзьями

Друзья = innovators (2.5% Rogers). 5-10 гаражей = MVP.
Обратная связь → фиксы → город → РФ.

## Хук

«Умное авто за 12-30к из любой машины. Голос + диагностика + тюнинг.»
