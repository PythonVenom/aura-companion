# ADR-152: AuraOS Desktop Environment (LXQt + Openbox)

## Контекст
Plasma 6.8 потеряла поддержку X11, что критично для драйвера NVIDIA 470 (Pascal). 
Нам нужна среда с минимальным потреблением RAM, работающая на X11, с поддержкой виджетов и интуитивным интерфейсом (как в GNOME/Ubuntu).

## Решение
Выбираем связку **LXQt + Openbox**.
Для управления конфигурацией используем паттерн "Провижионер" (Infrastructure as Code).
Вся конфигурация панели описывается в файле `aura/os/desktop/spec.yaml` (YAML). 
Скрипт `provision.py` читает YAML и генерирует валидный `panel.conf` для LXQt.

## Последствия
* Плюсы: Легковесность, стабильность X11, идемпотентность (один скрипт настраивает систему сколько угодно раз), версионирование рабочего стола.
* Минусы: Требуется написание и поддержка собственного провижионера.
