# Первый запуск Aura

## Что происходит

После первого запуска (или после установки) Аура предложит
настроить 3 параметра:

1. Имя ассистента (по умолчанию «Аура»)
2. Скорость речи (0.5–2.0)
3. Громкость (0–100)

Настройки сохраняются в `~/.config/aura/settings.json`.

## Как запустить вручную

    cd ~/aura_project
    source venv/bin/activate
    python -m aura.config_wizard

Пример диалога:

    === Aura — первая настройка ===

    1. Как называть ассистента?
       (по умолчанию: Аура. Можно: Катя, Маруся, Света, Дед...)
    Имя [аура]: катя

    2. Скорость речи (0.5=медленно, 2.0=быстро)
    Скорость [1.0]: 0.8

    3. Громкость голоса (0–100)
    Громкость [100]: 80

    === Готово! ===
      Имя: катя
      Скорость: 0.8
      Громкость: 80

## Изменить потом

    aura settings set wake_word маруся
    aura settings set tts_speed 1.2
    aura settings set volume 90

Посмотреть всё:

    aura settings show

## Wake-word: варианты

По умолчанию Аура слышит:
- **Аура**
- Ара
- Ура
- Алло
- Аула

Если имя пользователя другое (например, «Катя») — добавь его
в `wake_word_aliases`:

    aura settings set wake_word_aliases '["катя", "катюша", "катерина"]'

## Для бабушек

Просто запусти wizard — 3 вопроса, 30 секунд, готово.

На коробке (flash-install) wizard запускается автоматически
при первом старте.
