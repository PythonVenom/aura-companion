# Как я собрал бортовой компьютер для бати за 2 месяца

## История
Меня зовут Воронин Иван. Я строитель. У меня батя — ему нужна помощь.
Я не программист. Но я собрал ИИ-платформу, которая заботится о нём.

## Проблема
Облачные ассистенты (Alexa, Siri) — данные уходят в корпорации.
Для elder-care это критично: лекарства, падения, SOS.

## Решение
Aura — локальный ИИ-компаньон:
- Голос (T-one + Piper)
- 77 агентов
- 1610 тестов
- Elder-care (батя)
- GPLv3 + MIT

## Результаты
- 77 агентов
- 1610 тестов
- 2533 диалога (RAG)
- 115 ADR
- 11 платформ
