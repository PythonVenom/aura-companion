# Установка Aura для друга (5 шагов)

**Время:** 15-20 минут. **Нужно:** флешка >=4 ГБ, ноутбук с UEFI.

## Шаг 1. Записать образ на флешку

**Linux:**
    sudo dd if=aura-linux-x86_64.iso of=/dev/sdX bs=4M status=progress

**Windows/macOS:** balenaEtcher (https://etcher.balena.io/) -> Select image -> Select target -> Flash.

ВНИМАНИЕ: все данные на флешке будут стёрты.

## Шаг 2. Загрузиться с флешки

1. Вставь флешку, выключи ноут
2. Включи и сразу жми F12 (иногда F2, F10, Esc, Del — зависит от ноута)
3. В меню выбери USB или UEFI: <имя флешки>
4. Если не сработало — другой USB-порт, выключи Secure Boot в BIOS

## Шаг 3. Запустить установщик

Установщик запустится сам. Дальше — 3 вопроса:

| Вопрос | Что ответить |
|---|---|
| Диск для установки | Номер диска из списка (например sda). Будет стёрт |
| Пароль для aura | Придумай (>=6 символов: буквы, цифры, _, -) |
| Sudo без пароля? | N (рекомендуется). y — только если хочешь как у основателя |

Подожди 10-15 минут. Компьютер перезагрузится сам.

## Шаг 4. Первый вход

1. Логин: aura
2. Пароль: тот, что задал
3. Сохрани root-пароль, который показал установщик

## Шаг 5. Онбординг

Aura запустится сама. Ответь на 9 вопросов (имя, пол, роль, характер...). Один раз — навсегда.

Готово. Скажи «Аура, привет» — она ответит.

---

## Если что-то пошло не так

| Проблема | Решение |
|---|---|
| Не грузится с флешки | Secure Boot off в BIOS, другой USB-порт |
| Aura молчит | systemctl --user status aura — проверь статус |
| Нет звука | pavucontrol -> убедись что PipeWire видит устройство |
| Забыл пароль aura | Загрузись с флешки снова, установи заново |

Обратная связь: напиши основателю. Ты — тестер #1.
