# Aura для Astra Linux

Astra Linux SE (Debian-based) + ГОС-сектор РФ.

## Установка

    curl -fsSL https://raw.githubusercontent.com/PythonVenom/aura-companion/master/install_universal.sh | bash

## Особенности Astra

- **PARSEC** — мандатный контроль доступа. Aura не нарушает.
- **Сертификация ФСТЭК** — не требуется (Aura не реализует функции безопасности).
- **READY FOR ASTRA** — программа партнёрства.

## Программа READY FOR ASTRA

1. Подписать оферту
2. Отправить заявку: `readyfor@astralinux.ru`
3. Пройти испытания на совместимость
4. Получить статус «Технологический партнёр»
