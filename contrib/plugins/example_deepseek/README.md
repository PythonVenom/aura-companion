# DeepSeek AI Plugin

**Версия:** 1.0.0
**Риск:** cloud (данные уходят с устройства)

## Что делает

Позволяет Aura отправлять задачи в DeepSeek API через голос.

## Отказ от ответственности

Этот плагин использует внешний API. Устанавливая его, вы:
1. Согласны с условиями провайдера DeepSeek
2. Берёте на себя риск утечки данных
3. Отвечаете за расходы на API (свой ключ)

Aura не связана с провайдером, не несёт ответственности.
