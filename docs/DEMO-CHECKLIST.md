# Demo Checklist — что показываем в видео

**Правило:** каждая фишка должна быть ✅ (проверена) до съёмок.
❌ = не работает. ⚠️ = работает, но хрупко. ⬜ = не проверено.

## 1. Работа (готово, база)

| Фишка | Голос | CLI | Статус |

| Напоминание | «напомни через 5 мин» | `reminder 5` | ⬜ |
| Стройматериалы | «плитка 29» | `calc плитка 29` | ✅ |
| Метроном | «метроном 120» | `bpm 120` | ✅ |

| Погода | «погода Волгоград» | — | ✅ |

## Итог по видео

**Демо = связка:**
1. Приветствие + онбординг (persona)
2. Работа: таймер + стройматериалы + массаж
3. Медиа: включи музыку → следующий трек (silent)
4. **Окна: стол 2 → обзор → выбор приложения → открылось**
5. **Стоп: «Аура стоп» во время речи → замолчала → «продолжи»**
6. Финал: цифры (1115 тестов, 48 ADR, всё локально)

**Что обязательно починить до видео:**
- Barge-in (стоп)
- Workspace switching (проверить что работает)
- Overview (проверить)
- App launcher (проверить)
