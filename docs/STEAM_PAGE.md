# AURA — Steam Store Page (draft)

## Short Description (300 chars max)

AURA — локальный AI-компаньон для elder-care. 110 агентов, рой,
стигмергия. Помогает пожилым: SOS, падения, лекарства, звонки,
защита от мошенников. Всё локально, без облаков. MIT.

## About This

**AURA — не облачный ассистент. Это корабль, который живёт на вашем ПК.**

110 модулей-агентов объединяются в рой. Они общаются через
blackboard (бортовой журнал), координируются через граф связей,
и работают как единый экипаж.

**Для кого:**
- Семьи с пожилыми родственниками.
- Люди, ценящие приватность (всё локально).
- Технари, которые хотят кастомизировать ассистента.

**Что умеет:**
- 🆘 SOS: экстренный вызов помощи
- 🚨 Fall: детектор падений
- 💊 Meds: напоминания о лекарствах
- 📞 Call: звонки близким
- 🛡️ FinElder: защита от мошенников
- 🎙️ Голос: распознавание пользователя (F-074)
- 🔊 Ducking: приглушение музыки при разговоре

**Технологии:**
- Python 3.12 + asyncio
- Ollama (qwen2.5:7b)
- ChromaDB (RAG)
- PipeWire (audio)
- MCP (Model Context Protocol)

**Steam Workshop:**
- Плагины агентов (сообщество)
- Голосовые паки
- Сценарии elder-care
