# ADR-002: Интеграция Orchestrator в systemd

## Статус
Принято. 2026-09-20.

## Контекст

Модульная архитектура `aura/` (9 агентов, 174 теста) готова,
но не подключена к живому процессу. Монолит `aura_core.py` (604 строки,
83 агента в старой папке `agents/`) — единственная работающая система.

Нужно: подключить Orchestrator к проду, не рискуя сломать работающую Ауру.

## Решение

1. **Новая точка входа** `aura_main.py`:
   - Переиспользует `AgentListener` и `AgentSpeaker` из `agents/` (проверенные)
   - Роутинг команд — через `build_orchestrator()` из `aura/bootstrap.py`
   - Логика цикла повторяет монолит (анти-эхо, активация по «Аура»)

2. **Флаг переключения** `AURA_USE_ORCHESTRATOR=1`:
   - В `run_aura.sh`: если флаг есть → `aura_main.py`, иначе → `aura_core.py`
   - В systemd-юните: `Environment="AURA_USE_ORCHESTRATOR=1"`
   - Откат: убрать строку из юнита, `daemon-reload`, `restart`

3. **Монолит не удаляем**:
   - `aura_core.py` остаётся как рабочий fallback
   - Удалим только после полной миграции всех 80 агентов

4. **Бэкапы**:
   - `run_aura.sh.bak_core` — старая версия лаунчера
   - `~/.config/systemd/user/aura.service.bak_core` — старый юнит

## Обнаруженные проблемы

### Проблема 1: Буферизация stdout
`print()` в Python не выводится сразу при работе через `timeout` и pipe.
**Решение:** `PYTHONUNBUFFERED=1` в юните.

### Проблема 2: UnicodeEncodeError в wttr.in URL
`urlopen` требует ASCII-safe URL. В format-строке было `+ветер+%w` —
русские буквы, не закодированные.
**Решение:** заменить на `+wind:+%w`. Позиция 71-75.

### Проблема 3: T-one streaming даёт дубли
Пример: `'аура который час аура которыйч'`.
**Решение:** пока не решаем — Orchestrator справляется.
Отдельная задача на потом.

## Последствия

**Положительные:**
- Модульная архитектура в проде
- 8 агентов работают голосом
- Тесты 174 зелёные
- Откат за 10 секунд

**Отрицательные:**
- Монолит всё ещё в проекте (временное дублирование)
- `aura_main.py` повторяет цикл монолита (потенциальный drift)

**Риски:**
- Если Orchestrator упадёт в проде — systemd перезапустит через 5 секунд
- Если сломается сам `aura_main.py` — откат на монолит

## Проверка

Проверено вживую через голос:
- `который час` → `10 часов 41 минута утра, Создатель` (AgentTime)
- `громкость пять` → `🔊 Громкость: 5 из 10 (50%)` (AgentAudioPult)
- `погода в Москве` → `🌤 Погода: Москве: ☀️ +15°C, wind: ↗16km/h` (AgentInternet)
