# ADR-006: Barge-in — архитектура

## Дата
2026-09-21

## Статус
Принято

## Контекст

**Проблема:** Ауру нельзя перебить. Пока она говорит, микрофон
фактически не слушается — цикл спит на `is_speaking`.
У Алисы barge-in работает — Аура должна тоже.

**Что есть:**
- `agents/barge_in.py` — мёртвый (ADR-004).
- `aura_main.py:130` — `if is_speaking: time.sleep(0.1); continue`.
- `aura_main.py:163` — `stop_speaking()` есть, но недостижим.

**Проверено:** два `InputStream` одновременно работают (ALSA).
`sd.query_hostapis()` → ALSA. Тест двух потоков — OK.

## Варианты

### Вариант A — общий аудио-поток (fan-out)

`listener._audio_callback` кладёт фрейм в две очереди: для T-one
и для VAD. Barge-in читает вторую. Один InputStream.

**Плюс:** один микрофон. **Минус:** рефакторинг `listener`.

### Вариант B — отдельный постоянный поток

Barge-in держит **свой** InputStream открытым. VAD в фоне.
Не открывает-закрывает.

**Плюс:** `listener` не трогаем. Полная независимость.
**Минус:** два потока. **Проверено:** работают.

### Вариант C — кустарный (отвергнут)

Открыть-закрыть микрофон на 300 мс. Техдолг. Отвергнут.

## Решение

**Вариант B — отдельный постоянный поток.**

**Обоснование:**
- Наука — качество, а не простота. B — правильный, A — компромисс.
- Тест подтвердил: два InputStream работают (ALSA + dmix).
- `listener` не трогаем — минимум риска для T-one.
- Масштабируемо: wake word, детект тишины, детект шума — на том же потоке.
- Как у Алисы — в промышленных системах так и делают.

## Архитектура

### `aura/agents/barge_in.py` — сервис (не агент)

- НЕ наследует BaseAgent. Как `brain`, `tool_router`.
- Свой `sd.InputStream` (`sample_rate=16000`, `blocksize=480`).
- VAD `webrtcvad.Vad(2)`.
- `start(on_speech)`: открывает поток, VAD в фоне.
- `stop()`: закрывает.
- `set_aura_speaking(bool)`: флаг — Аура говорит.
- Фоновый цикл: читает фреймы, VAD, если речь и `aura_speaking` — callback.

### `aura_main.py`

- До цикла: `barge.start(on_speech=speaker.stop_speaking)`.
- В цикле: `barge.set_aura_speaking(self.speaker.is_speaking)`.
- Убрать: `if is_speaking: time.sleep(0.1); continue` — не спать.
- Когда Аура говорит — цикл продолжается. `listen()` вернёт None
  (listener.active = False пока говорим — или ждём).

## Последствия

**Положительные:**
- Barge-in работает как у Алисы.
- `listener` не тронут.
- Фундамент для wake word, детекта тишины.

**Отрицательные:**
- Два InputStream (проверено — OK).
- Новый паттерн — сервис с потоком.

**Риски:**
- Эхо: Аура сама себя перебьёт. Митигация: VAD только когда
  `aura_speaking=True`, агрессивность 2.
- Очередь фреймов растёт. Митигация: maxsize, отбрасывать старые.

## Проверка

Ручной прогон: «Аура, расскажи длинную историю». Когда Аура
говорит — сказать «стоп». Аура замолкает.

## Обновление 2026-09-21: эксперимент провалился

**Что сделали:**
- Реализовали `aura/agents/barge_in.py` (Уровень 3).
- Интегрировали в `aura_main.py`:
  - `set_aura_speaking(is_speaking)` — VAD активен только когда Аура говорит.
  - `if is_speaking: continue` — ANTИ-ЭХО для `listener`.
- Убрали костыль `set-sink-volume @DEFAULT_SINK@ 30%` (он мешал).

**Что произошло:**
- Первый прогон: Аура говорила 30+ сек, 8 раз `🎤 Распознано` — **эхо голоса Ауры**.
- Второй прогон (без костыля): Аура **начала говорить и затихла** — `stop_speaking()` **сработал на её собственном голосе** через микрофон.
- **Barge-in без AEC — не работает.**

**Диагностика:**
- `module-echo-cancel` (PipeWire) доступен.
- `echo-cancel-source` работает (`parecord` пишет).
- `sounddevice` видит `pipewire` (7), `pulse` (8), `default` (10).
- **Но** `echo-cancel-source` **не** сделан default. **PortAudio** видит **default** — **не** AEC.

**Решение:**
1. Откатили `aura_main.py` к рабочей версии (с костылём, без barge_in).
2. `aura/agents/barge_in.py` и тесты — **сохранены, не подключены**.
3. **Перед повторной попыткой нужно:**
   - Сделать `echo-cancel-source` default source: `pactl set-default-source echo-cancel-source`.
   - Проверить, что AEC **реально** вычитает голос Ауры из микрофона.
   - **Потом** — подключить `barge_in` снова.

**Статус:** отложено до реализации AEC.

**Связанные артефакты:**
- `aura/agents/barge_in.py` — код (не подключён).
- `tests/test_barge_in.py` — 6 тестов (зелёные).
- Костыль `set-sink-volume` — вернули (временно, до AEC).
