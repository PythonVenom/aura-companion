# ADR-007: AEC через PipeWire echo-cancel

## Дата
2026-09-21

## Статус
Принято

## Контекст

В ADR-006 мы решили делать barge-in (перебивание Ауры). Код
`aura/agents/barge_in.py` написан. Но интеграция провалилась:
barge-in срабатывал на эхо голоса Ауры — она сама себя перебивала.

Причина: микрофон слышит колонки. VAD детектит речь. Голос Ауры
из колонок = «речь пользователя» = stop_speaking().

Плюс — костыль `set-sink-volume @DEFAULT_SINK@ 30%`:
- Крутил **системный** ползунок (виден на экране).
- Мешал AEC (менял громкость, пока AEC считал разницу).
- Не разбирал источники (глушил всё).

## Решение

**Использовать PipeWire `module-echo-cancel` как default source.**

Команды:
- `pactl load-module module-echo-cancel` — загрузить модуль.
- `pactl set-default-source echo-cancel-source` — сделать источником по умолчанию.

`echo-cancel-source` — виртуальный источник PipeWire. Он вычитает
выход (что играет) из входа (микрофон). Голос Ауры — не слышен.
Твой голос — слышен.

Костыль `set-sink-volume` убран из `aura_main.py`.

## Как это работает

- `listener` (T-one) — `sd.InputStream()` **без device** → default source → `echo-cancel-source`. Эхо вычтено.
- `barge_in` (VAD) — то же. Позже, при подключении.
- `speaker` — играет через default sink. Не меняет громкость.

## Обоснование

- **AEC** — стандартный способ в audio-индустрии. У Алисы — есть.
- **PipeWire** — уже в системе (Arch, свежий). Модуль встроен.
- **Один микрофон** — нет конфликтов ALSA (проверено: два потока работают).
- **AEC** решает проблему **без** костыля и **без** правок кода.
- Проверено вживую: прогон без костыля, эхо не слышно, `🎤 Распознано` во время речи Ауры — нет.

## Последствия

**Положительные:**
- Эхо устранено на уровне системы.
- Ползунок громкости **не выскакивает** — UX улучшен.
- `listener` работает **чище** — T-one слышит **только** пользователя.
- Barge-in **можно** подключать (после проверки).

**Отрицательные:**
- `echo-cancel-source` **должен быть default** — если слетит, эхо вернётся.
- Зависимость от PipeWire (не от ALSA).
- При `pactl set-default-source` — **PipeWire restart** может сбросить. Нужно закрепить через конфиг (отдельная задача).

**Риски:**
- `module-echo-cancel` может **не загрузиться** при старте системы. Митигация: конфиг PipeWire (отдельная задача).
- AEC **добавляет** задержку (~10–20 мс). Для T-one — приемлемо.

## Проверка

1. `pactl get-default-source` → `echo-cancel-source`.
2. Прогон `aura_main.py`: сказать длинную историю. Молчать. Аура **договаривает** до конца. Нет `🎤 Распознано` во время речи.
3. Ползунок громкости **не выскакивает**.
