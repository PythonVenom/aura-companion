# ADR-014: Proactive Assistant — Аура сама инициирует диалог

## Дата
2026-09-26

## Статус
Принято

## Контекст

Сейчас Аура **реактивная**: ждёт «Аура ...», отвечает, замолкает. Это стандартная модель голосовых ассистентов (Алиса, Siri, Google).

**Но у Ауры есть уникальная возможность:** быть **проактивной**. Сама инициировать диалог, когда:
- Утро — брифинг дня.
- Важное сообщение в чате.
- Приближается событие (встреча, звонок).
- Три дня не звонил маме.
- Проект на GitHub обновился.

**Что говорит наука:**
> **Proactive Conversational Agent** — Rasa, 2023. Проактивность — самый сложный уровень диалоговых систем. Требует: триггеры, контекст, право на инициативу.

**У Джарвиса (Marvel) есть это.** У Алисы — нет. У нас есть шанс **обогнать** рынок именно здесь.

## Решение

**Многоуровневая проактивность** с чёткими правилами.

### Четыре уровня

| Уровень | Что делает | Триггер |
|---|---|---|
| **1. Реактивный** | Отвечает на «Аура ...» | Голос |
| **2. Брифинг** | Утренний отчёт | Время / «доброе утро» |
| **3. Напоминания** | Будильники, таймеры | Точное время |
| **4. Подсказки** | Наблюдения, паттерны | События, аналитика |

### Уровень 1 — Реактивный (есть)

Текущая модель. Работает.

### Уровень 2 — Брифинг (Фаза 17)

**Когда срабатывает:**
- **Утро** (первое обращение к ПК после 6:00, или time-based триггер).
- Голосовая команда «доброе утро» / «что нового».
- По расписанию (systemd timer, 08:00).

**Что говорит:**
1. **Приветствие** — «Доброе утро, Создатель».
2. **Погода** — «Сегодня +5, дождь. Зонт».
3. **Календарь** — «В 14:00 — массаж. В 19:00 — созвон с Иваном».
4. **Сообщения** — «В Максе 3 новых: Петруха, ЛПК, мама».
5. **GitHub** — «Aura: 2 новых issue».
6. **Почта** — «2 письма: счёт от хоста, ответ от AMD».
7. **Задачи** — «В журнале 4 незакрытых».
8. **Планы** — «Вчера писал install.sh. Продолжить?».

**Стиль:** короткий, игривый, **паузы между блоками 2–3 сек**. Общая длина — **не более 60 секунд**.

**Право на отказ:** если скажешь «хватит» / «не сейчас» / «спасибо» — Аура замолкает.

### Уровень 3 — Напоминания (Фаза 18)

**Команды:**
- «Аура, напомни через 30 минут про X».
- «Аура, будильник на 7:00».
- «Аура, напомни вечером позвонить маме».

**Голосовое срабатывание:**
- «Создатель, 30 минут прошло. X».
- «Доброе утро, Создатель. 7:00».

**Интеграция:** `speaker.say` + `listener` feedback.

### Уровень 4 — Подсказки (Фаза 20)

**Что наблюдает:**
- **Чаты** — новые события («запись на массаж в 14:00»).
- **Почта** — важные письма.
- **GitHub** — issues, PR, звёзды.
- **Календарь** — приближающиеся события.
- **Журнал** — незакрытые задачи.

**Правило:** подсказка **только** если:
- Она **полезна** (событие, важное).
- Не повторяется (**правило 3 дней**).
- Учитывает **контекст** (не отвлекает, если ты в звонке).

**Примеры:**
- «Ты 3 дня не звонил маме».
- «В Максе новое сообщение от Петрухи».
- «Звонок через 15 минут».
- «Ты вчера писал install.sh. Продолжим?».

### Формат подсказок

**Голосом + опционально в виджет:**
- **Длина:** ≤ 2 предложений.
- **Тон:** игривый, но не навязчивый.
- **Право на отказ:** «не сейчас», «потом», «стоп».
- **Тишина:** если 3 раза сказал «не надо» — не повторять 24 часа.

## Правила проактивности

### Что **разрешено**

- ✅ Утренний брифинг.
- ✅ Напоминания по запросу.
- ✅ Критичные события (встреча через 15 минут).
- ✅ Сообщения от близких (мама, партнёр).
- ✅ GitHub issues на твой проект.

### Что **запрещено**

- ❌ **Реклама** (никогда).
- ❌ **Маркетинг** (никогда).
- ❌ **Push из облака** (только локальное — односторонний шлюз).
- ❌ **Ночью** (после 23:00 — тишина, если не срочно).
- ❌ **Во время звонка** (если видит, что ты в звонке).
- ❌ **Навязчивые повторения** (правило 3 дней).

### Право на тишину

Пользователь может:
- **Отключить** любой уровень проактивности.
- **Настроить** время (брифинг в 9:00, а не в 7:00).
- **Сказать** «не беспокоить».
- **Сказать** «только срочное».

## Архитектура

### Модуль `aura/agents/proactive.py`

```python
class ProactiveEngine:
    def register_trigger(self, trigger: Trigger): ...
    def on_tick(self): ...   # вызывается раз в 30 сек
    def check(self): ...     # проверяет все триггеры

class Trigger:
    name: str           # "morning_briefing"
    condition: Callable # возвращает True / False
    action: Callable    # что сказать
    cooldown: int       # сколько сек не повторять
    priority: int       # 1-5
```

### Интеграция с главным циклом

```
while self.running:
    proactive = self.proactive.check()
    if proactive:
        self._say_with_duck(proactive)
```

### Триггеры первого набора (Фаза 17)

1. **morning_briefing** — время 8:00, раз в день.
2. **greeting** — «доброе утро» голосом.
3. **new_message** — новое сообщение в Максе (Фаза 13.4).
4. **upcoming_event** — событие через 15 мин (Фаза 19).
5. **unfinished_task** — незакрытая задача 3 дня (Фаза 20).

## Обоснование

- **Proactive dialogue** — Rasa, 2023; Jurafsky & Martin, глава 24.
- **Уникальность:** у Алисы нет. У Джарвиса есть.
- **Приватность:** локально, без push.
- **Право на тишину:** фундамент privacy-by-design.
- **Поэтапность:** 4 уровня, каждый — отдельная фаза.

## Последствия

### Положительные
- Аура — не «Алиса в терминале», а **спутник**.
- Утренний ритуал — привычка, ежедневное использование.
- Проактивность → уникальность на рынке.
- Стиль Джарвиса → эмоциональная привязка.

### Отрицательные
- Сложнее тестировать (время, триггеры).
- Риск **навязчивости**.
- Нужны **источники данных** (календарь, чаты, почта, GitHub).

### Риски
- **Перегрузка пользователя.** Митигация: право на тишину, ≤60 сек.
- **Ложные срабатывания.** Митигация: cooldown, priority.
- **Утечка данных.** Митигация: всё локально.
- **Зависимость от источников.** Митигация: деградация — если источник недоступен, пропустить.
