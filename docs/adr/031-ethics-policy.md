# ADR-031: Ethics Policy

**Дата:** 2026-09-28
**Статус:** Принято

## Контекст

Развитие Aura открывает соблазнительные рынки:
- Промышленный мониторинг рабочих («кто бездельничает»)
- Биржевые сигналы («покупай X»)
- Медицинские советы («у вас болезнь Y»)

Технически — легко. Юридически и этически — **красная зона**.

## Решение

**Aura не делает три класса задач.** Reject List важнее Feature List.

### 1. Наблюдение за людьми без их согласия

**НЕ делаем:**
- Мониторинг рабочих (продуктивность, «бездельники»)
- Слежка за членами семьи (дети, партнёры, пожилые без согласия)
- Сбор метрик сотрудников

**Почему:**
- РФ: 152-ФЗ + ст. 86 ТК РФ — штраф до 1 млн ₽, уголовка
- ЕС: GDPR + AI Act — запрещено в Италии, Германии, Франции
- Этика: противоречит миссии «проводник», а не «надзиратель»

**Исключение:** мед/социальное наблюдение **с письменным согласием** (напр. родитель-опекун + ребёнок с ОВЗ).

### 2. Финансовые рекомендации

**НЕ делаем:**
- «Купи Газпром», «продай биткоин»
- Автотрейдинг без ведома пользователя
- Инвестиционные советы

**Почему:**
- РФ: 39-ФЗ «О рынке ценных бумаг» — инвестиционный советник требует лицензии ЦБ
- Штраф до 1 млн ₽ + ответственность за ущерб

**Можно:** показать данные (котировки), выполнить команду пользователя (алготрейдинг через API брокера, ответственность на нём).

### 3. Медицинские диагнозы и лечение

**НЕ делаем:**
- «У вас депрессия»
- «Принимайте X мг»
- Замена врача

**Почему:**
- ФЗ-323 «Об основах охраны здоровья» — медицинская деятельность лицензируется
- Ответственность за вред

**Можно:** фиксация (диктовка), напоминания, RAG по истории, отчёты. **Врач решает, Аура — помогает.**

## Последствия

**Плюсы:**
- Юридическая чистота
- Доверие пользователя (важно для accessibility)
- Не размывает фокус (Pareto)

**Минусы:**
- Отказ от части рынков (промышленность, финтех)
- Медленнее монетизация

**Решение:** долгосрочный марафон > быстрая нажива.
