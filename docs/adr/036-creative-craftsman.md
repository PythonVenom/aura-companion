# ADR-036: Creative & Craftsman Vertical

**Дата:** 2026-09-28
**Статус:** Проект
**Связано:** strategy-2026.md, ADR-026, ADR-030

## Контекст

Мастера, дизайнеры, врачи-процедурники, водители — **руки заняты**.
Им не нужна «умная колонка». Им нужен **голосовой ассистент рабочего места**.

## Решение

**Aura Craft** — 5 агентов-кластеров, а не 50 агентов под профессии (YAGNI).

### Агенты (5 кластеров)

1. **GlovesOnAgent** — руки в перчатках
   - Медицина (расширение ADR-026)
   - Тату, косметология, лаборант, повар

2. **ToolAgent** — руки на инструменте
   - ЧПУ, лазер, 3D-печать, сварка, авто (OBD), электрика

3. **ShortcutAgent** — руки на клаве
   - Дизайнеры (Figma/PS), 3D (Blender), музыканты (DAW), аналитики (Jupyter)

4. **WheelAgent** — руки на руле
   - Дальнобойщики, курьеры, пилоты дронов, такси

5. **CraftAgent** — глаза на изделии
   - Художники, пекари, тренеры, парфюмеры, ювелиры

### Стек интеграций

- **Blender:** Python API (`bpy`)
- **Photoshop/Figma:** плагины + keyboard emulation
- **DAW (Ableton/FL/Reaper):** OSC, MIDI
- **AutoCAD/Fusion/SolidWorks:** Python API / COM
- **ЧПУ (GRBL/LinuxCNC):** serial / gRPC
- **Lightroom/DaVinci:** Lua / Python
- **Jupyter:** Jupyter kernel protocol

### Отличие от Copilot (science: differentiation)

- **Copilot** = набор текста в IDE (руки на клаве)
- **Aura Craft** = **голос при занятых руках** (новый JTBD)
- **Не конкуренты**, а дополнения

### Монетизация

- Free: до 3 сессий в день
- Pro: 1490 ₽/мес — unlimited + все 5 кластеров
- Studio: 4990 ₽/мес — для мастерских (10+ устройств)

### НЕ делаем (ADR-031)

- Замену дизайнера/художника (Аура помогает, не творит)
- Автоматизацию без ведома (кроме явных команд)
- Советы по технике безопасности на производстве (лицензия)

## Последствия

**Плюсы:** 30+ профессий, огромный TAM, diff от Copilot
**Минусы:** много интеграций (Blender, PS, DAW, ЧПУ)
**Сроки:** Q2-Q4 2026, по одному агенту в квартал
