# ADR-044: Founder-First Beachhead

**Дата:** 2026-09-28
**Статус:** Принято

## Контекст

ADR-036 (5 кластеров x 110 профессий) размывает фокус.
Crossing the Chasm: нужен beachhead — узкий сегмент, где продукт №1.
Founder-Market Fit (YC): основатель = целевой пользователь.

## Решение

**Beachhead = основатель** (Q4 2025 - Q1 2026).

Первый пользователь — сам автор (массажист + программист +
строитель + музыкант + повар + спортсмен). 6 контекстов.
