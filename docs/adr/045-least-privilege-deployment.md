# ADR-045: Least-Privilege Deployment

**Дата:** 2026-09-28
**Статус:** Принято
**Связано:** ADR-019 (Installation Experience), ADR-021 (Flash-install), ADR-022 (Cross-platform)

## Контекст

Для нетехнических пользователей (бабушки, незрячие, моторные ограничения)
Aura должна «настроиться один раз и работать всегда». Возникает соблазн
поставить её как system service с root — «чтобы точно работало».

Это опасно: LLM-цепочка недетерминирована, баги уровня Bug E/F/D ловятся
на ровном месте. С root один баг парсера = потеря `/usr`.

## Решение

### Принцип: user-service first, root только для установки пакетов

**Aura — user service.** Всё основное (микрофон, TTS, файлы, сеть, браузер,
MPRIS, PipeWire) доступно пользователю. Root не даёт ничего из этого.

**Root используется только:**
- установка системных пакетов (Ollama, Piper) — через `pkexec`/`sudo` диалог ОС
- опционально: ярлык в системном меню

**Root НЕ используется:**
- для работы ассистента
- для доступа к файлам пользователя
- для сети
- для управления окнами / микрофоном / звуком

### Установка (бабушкин сценарий)

1. Flash / сайт → `~/.local/share/aura/`
2. ОС спрашивает разрешения (микрофон, автозапуск) — стандартный диалог
3. `systemctl --user enable aura.service` — автозапуск
4. Кнопка «обновить» в UI, без терминала
5. Кнопка «удалить», без терминала

### Что это даёт

- Ошибка в Aura не ломает систему
- Обновление не требует root
- Удаление не требует root
- Совместимо с ADR-022 (systemd / launchd / Task Scheduler)

### Что это НЕ даёт

- Aura не может ставить пакеты без запроса ОС
- Aura не может читать чужие `/home/*`
- Aura не может слушать порты <1024

Все три пункта не нужны продукту.

## Последствия

- `contrib/flash/install-aura.sh` регистрирует user service, не system
- NOPASSWD — опционально, по явному запросу пользователя (default N)
- Флаг `--system` (для продвинутых) — отдельная задача, не 1.0.1
- В README: «Aura не требует root для работы»
- `aura doctor` проверяет, что сервис user-level

## Что НЕ делаем (YAGNI)

- system service по умолчанию
- набор root-операций в API ассистента
- «полный доступ по галочке» (нет механизма отзыва)
