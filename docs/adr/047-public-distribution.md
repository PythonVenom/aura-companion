# ADR-047: Public Distribution

**Дата:** 2026-09-28
**Статус:** Принято
**Связано:** ADR-019 (Installation), ADR-021 (Flash-install), ADR-022 (Cross-platform), ADR-045 (Least-Privilege)

## Контекст

Aura работает у основателя. Пора дать её другому человеку (друг, пилот, бабушка).
Сейчас каналов раздачи нет: iso не собирается, сайта нет, installer тестирован только на бумаге.

Нужна стратегия: как любой желающий получает Aura, не заходя в терминал.

## Решение

### Три канала раздачи (в порядке появления)

**Канал 1 — Flash (для друга), v1.0.1:**
- Готовый `.iso` собирается через mkarchiso (contrib/flash/profile/)
- Друг: скачал образ → записал на флешку (`dd`/balenaEtcher) → F12 → installer
- 3 экрана installer: диск, пароль, имя ассистента
- Результат: работающая Aura через 15-20 мин

**Канал 2 — Website (для любого), v1.0.2:**
- Статический сайт на GitHub Pages (YAGNI: не WordPress)
- Кнопки: Linux / Windows / macOS
- Linux: `.iso` (ссылка на GitHub Releases)
- Windows/macOS: `.exe` / `.dmg` — после ADR-022 портов
- Плюс: Demo-видео, README, ссылки на CloudTips/Boosty

**Канал 3 — Пакетные менеджеры (для энтузиастов), v1.1+:**
- AUR (`aura-bin`)
- AppImage (portable, работает везде где glibc)
- Homebrew (macOS, если порт удастся)

### Первый тестер = друг

- Друг #1 получает флешку лично от основателя
- Отзывы → `docs/testers.md` (трекер)
- 10 друзей → 10 пилотов
- 100 пилотов → публичный релиз

### Что НЕ делаем (YAGNI)

- Свой сервер/домен (GitHub Pages хватает)
- Собственный CDN (GitHub Releases + LFS)
- Телеметрия (этика ADR-031)
- Авто-обновление в фоне (кнопка «проверить обновление» — достаточно)
- Платная подписка до 100 пользователей

## Последствия

- `contrib/flash/profile/` — реальный mkarchiso-профиль (не .txt)
- `docs/install-friend.md` — 5 шагов для друга
- `docs/testers.md` — таблица пилотов
- Сайт (позже) — статика в `docs/site/` или отдельный репо
- GitHub Releases: каждый тег → iso в assets
