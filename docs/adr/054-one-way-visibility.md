# ADR-054: Односторонняя видимость

**Статус:** Принято (перенесено из VISION-2026-09-30)
**Дата:** 2026-09-30

- Дочери видят интернет. Интернет их — нет.
- Никаких listening-портов. Только исходящие соединения.
- Ядро никогда не инициирует контакт с дочерью. Дочь сама стучится.
- Ядро слушает только loopback (127.0.0.1). Для «путешествия» — ядро запускается локально.
- Attack surface = 0 (входящий). Единственный вектор — локальная компрометация.
- «Ауры видят интернет, интернет их нет. Всё. Точка.»
