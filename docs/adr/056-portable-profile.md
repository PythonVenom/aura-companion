# ADR-056: Portable-профиль

**Статус:** Принято (перенесено из VISION-2026-09-30)
**Дата:** 2026-09-30

- .aura/ в home + скрипт export/import.
- «Путешествие» начинается с возможности унести с собой.
- Потом — зашифрованный контейнер.
- Физический носитель как транспорт. Никакой network-синхронизации.
- Никакого облака. Никаких серверов. Пришёл, взял, ушёл.
