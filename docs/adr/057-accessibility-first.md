# ADR-057: Ассистент как опора (accessibility-first)

**Статус:** Принято (перенесено из VISION-2026-09-30)
**Дата:** 2026-09-30

- Не «помощник». Протез. Когнитивный и физический.
- Первый пользователь — автор. Грыжи, протрузии, биполярка, шизофрения в ремиссии.
- Забываю пить, есть, таблетки, сон. Aura — опора.
- Все решения фильтруются через: «помогает ли это человеку с особенностями?»
- Референсы: NVDA, Windows Voice Access, macOS Voice Control, GAVI, EasySpeak.
- Отличие: кросс-платформенность + агенты + portable-профиль + pull-модель.
