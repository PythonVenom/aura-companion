# ADR-058: Активная оборона (honeypot + tarpit)

**Статус:** Принято (перенесено из VISION-2026-09-30)
**Дата:** 2026-09-30

- Aura = файрвол + контроль портов + интеграция с ClamAV/YARA/nftables/fail2ban.
- Honeypot: фальшивые порты, фальшивые сервисы. Логирование атак.
- Tarpit: удержание противника. Медленные ответы. Бесконечные комнаты.
- «Куб»: фальшивые комнаты, противник ходит по кругу, пока не сдохнет.
- Референсы: Endlessh, LaBrea, Cowrie, T-Pot, OpenCanary.
- Юридически: entrapment — серая зона. Лимит: 1 противник — 1 комната. Больше — бан.
- Не сейчас. v2.0.
