# ADR-060: Экстренное реагирование с мультимодальной верификацией

**Статус:** Принято (перенесено из VISION-2026-09-30)
**Дата:** 2026-09-30

- Детект: падение, нет движения, звук distress.
- Верификация: голосовой вопрос + анализ ответа + контекст + история + тон.
- Действие:
    - Нет ответа или «помогите» → вызов скорой.
    - Рядом есть люди → инструктаж («Не паникуйте. Проверьте дыхание. Скорая едет.»).
    - «Всё хорошо» → отмена, логирование.
- Референсы: Smart Companion 2 (Австрия), Philips Lifeline (патент US20210352176A1),
  Holo Alert (Канада), RapidSOS (США).
- Инструктаж окружающих — новое. Прямого аналога нет.
- Не сейчас. v2.0.
