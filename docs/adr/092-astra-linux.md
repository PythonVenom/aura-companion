# ADR-092: Astra Linux + РФ госсектор

**Дата:** 2026-10-02
**Статус:** Проект

## Контекст

Astra Linux SE — №1 ОС для госсектора РФ. Debian-based.
Программа "READY FOR ASTRA" — партнёрство с разработчиком.

## Решение

1. **Astra совместимость** через install_universal.sh (apt уже поддержан).
2. **PARSEC** — Aura не нарушает мандатный контроль (не работает с чувствительными файлами).
3. **Не сертифицируемся у ФСТЭК** (Aura не реализует функции безопасности).
4. **Заявка на READY FOR ASTRA** — партнёрство.

## Позиционирование для госсектора

- **Accessibility-first** — требование законодательства РФ
- **Локально / No cloud** — ФЗ-152 compliance
- **Open source** — IT может проверить код
