# ADR-093: Copilot Mode (R2-D2)

**Дата:** 2026-10-02
**Статус:** Проект

## Контекст
Пользователь = пилот. Руки заняты. Aura = астромех.
Не ждёт команду — уже работает в фоне.

## Решение
Copilot Mode: действует молча, держит периферию, помнит контекст.
