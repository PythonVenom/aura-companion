# ADR-095: Hands-Free Mode

**Дата:** 2026-10-02
**Статус:** Принято (MVP)

## Контекст
При работе (код, звук) руки заняты. Говорить «Аура» перед каждой
командой — трение. Нужен режим без активации.

## Решение
Flag-файл /tmp/aura_handsfree с timeout.
- enable(seconds=300) — 5 мин
- is_active() — проверка
- Голосом: «Аура, слушай без активации»
- Авто-сброс через timeout
- Голосом: «хватит слушать»

## YAGNI
- Не делаем always-on (privacy)
- Не делаем wake-word вместо
- Не делаем multi-user
