# ADR-155: Neuro-rights для Aura

## Дата
2026-10-05

## Статус
Принято.

## Контекст

Aura — локальный голосовой помощник для пожилых и людей с ограниченными
возможностями. В её составе:

- `emotion_voice.py` — анализ эмоций по голосу (RMS, ZCR, паузы)
- `proactive_alert.py` — тревога при молчании ≥ порога
- `reminiscence.py` — автобиографическая память
- `health_twin.py` — временной граф здоровья
- `soul_talk.py` — эмпатичный диалог

Все эти агенты **читают психические состояния** и **сохраняют**
автобиографические данные. По классификации Ienca & Andorno (2017)
это приближается к нейротехнологиям, даже без BCI.

**Риск:** без этических рамок система может стать инструментом слежки
или манипуляции, особенно для людей в уязвимом положении (пожилые,
ментальные особенности).

## Решение

Aura принимает **5 нейроправ** как технические требования к архитектуре.

### 1. Право на отказ

- Любой агент, читающий эмоции или память, может быть отключён
  через `config/agents.json` без перезапуска ядра.
- `emotion_voice`, `reminiscence`, `health_twin`, `proactive_alert`
  не активируются без **явной** активации в настройках.

### 2. Право на удаление

- Все данные психического профиля хранятся **локально** в `~/.local/share/aura/`:
  - `proactive.db` — тревога
  - `memories.db` — автобиография
  - `health_twin.db` — граф событий
  - `journal.db` — дневник
- `aura reset` — команда полного удаления.
- Никаких фоновых бэкапов в облако.

### 3. Право на объяснение

- Каждый агент возвращает `AgentResponse` с полем `reason`
  при эмоциональной оценке (`emotion_voice._classify` → `(emotion, reason)`).
- `health_twin._trace()` показывает путь между событиями.
- Пользователь всегда может спросить: «почему ты так решила?»

### 4. Право на приватность

- Все вычисления локальны: ASR (Vosk/T-one), TTS (Piper), LLM (Ollama).
- Нет телеметрии, нет аналитики, нет отправки «на улучшение».
- Данные не покидают устройство **по архитектуре**, не по обещанию.

### 5. Право на психическую целостность

- Aura **не** манипулирует эмоциями: не усиливает тревогу, не вызывает зависимость.
- `soul_talk.py` использует Active Listening (Rogers 1957), а не persuasion.
- `proactive_alert.py` — только эскалация семье, не скрытое давление.

## Обоснование

**Ienca & Andorno 2017** предложили 4 нейроправа: cognitive liberty,
mental privacy, mental integrity, psychological continuity. **Chile 2021**
закрепила их в конституции. **UNESCO 2025** расширила на BCI.

Aura не BCI, но работает с психическими данными, поэтому **применяет
те же принципы добровольно** — до того, как это потребует закон.

Это даёт:
- Доверие пользователей в уязвимом положении
- Соответствие будущим нормам (регуляторная фор-сайт)
- Этическую базу для federated learning и других симбиоз-фич

## Последствия

### Положительные
- Aura можно рекомендовать пожилым без страха «слежки»
- Готовность к будущему регулированию (РФ, ЕС, ООН)
- Ясные требования к агентам — что можно, что нельзя

### Отрицательные
- Некоторые фичи (эмоции, автобиография) **выключены по умолчанию** —
  пользователь должен явно включить
- Разработка медленнее: каждый агент проходит проверку на 5 прав
- Нельзя использовать «удобные» решения вроде cloud-fallback для эмоций
