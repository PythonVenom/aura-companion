# ADR-163

**Дата:** 2026-10-21
**Статус:** Accepted
: Boot Report — POST-диагностика при старте

Дата: 2026-10-14
Статус: Accepted
Контекст: elder-care, мониторинг 24/7.

## Проблема

После перезагрузки AURA не сообщает о своём состоянии. Пользователь
не знает: работает ли система, есть ли проблемы, что предпринято.

## Решение

Модуль aura/core/boot_report.py — POST (Power-On Self-Test).

5 проверок: doctor, агенты, RAG, elder-care, soak-test.
Формат: человекочитаемый + JSON в ~/.cache/aura/boot_report.json.
Статусы: ok / warnings / errors.
Интеграция: python -m aura.cli boot-report, автозапуск в aura/chat.py main().
Отключение: AURA_SKIP_BOOT_REPORT=1 (для тестов/CI).

## Обоснование

Почему POST: стандарт IBM PC BIOS (1981), проверен десятилетиями.
Почему 5 проверок: покрывают критические подсистемы.
Почему JSON + текст: JSON для интеграции, текст для человека.
Почему в chat.py: единственная точка входа пользователя.

## Последствия

Плюсы: прозрачность статуса, диагностика, интеграция с алертами.
Минусы: задержка старта +2-3 сек.
