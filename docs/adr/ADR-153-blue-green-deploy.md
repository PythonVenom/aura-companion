# ADR-153: Blue-Green Deployment for Aura

## Контекст
Aura — это живая система (systemd-сервисы, агенты, память). Обновление "на горячую" (git pull прямо в рабочей папке) может привести к падению сервиса из-за несовместимости зависимостей или ошибок в коде.

## Решение
Используем паттерн **Blue-Green Deployment** на уровне файловой системы.
- **Blue**: Текущая рабочая версия (стабильная).
- **Green**: Новая версия (кандидат).
- Переключение происходит мгновенно через изменение симлинка `/opt/aura/current`, который указывает на `blue` или `green`. Скрипт `deploy.sh` собирает код, запускает тесты. Если тесты пройдены — переключает симлинк и перезапускает `systemd`. Если нет — откатывает.

## Последствия
* **Плюсы**: Zero-downtime деплой, безопасность (откат в 1 команду), чистота.
* **Минусы**: Требуется дополнительное место на диске для двух версий.
