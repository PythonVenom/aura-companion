## Как читать

- **Принято** — реализовано или зафиксировано
- **Проект** — решено, но не реализовано
- **Отложено** — отложено до условий

## Как добавить

1. Скопировать `XXX-template.md`
2. Заполнить: Контекст, Решение, Последствия
3. Обновить README
4. Коммит `docs(adr): ADR-XXX`
