# Demo Aura — сценарий для OBS (2 минуты)

**Дата:** 2026-09-28
**Цель:** показать голосовой цикл + 5 сценариев за 2 минуты.

## Подготовка (перед записью)

- [ ] Firefox открыт: web.vk.com, web.telegram.org
- [ ] VLC установлен, локальная музыка в плейлисте
- [ ] Микрофон проверен (`arecord -d 3 test.wav`)
- [ ] Уведомления выключены (KDE Do Not Disturb)
- [ ] OBS: 1920×1080, 30 fps, микрофон + экран
- [ ] Свежий `aura.service` (restart)

## Команды для OBS

**Проверка перед записью:**

    arecord -d 3 /tmp/test.wav && aplay /tmp/test.wav
    systemctl --user status aura.service
    aura doctor

**Запуск записи:** OBS → Start Recording → пауза 2 сек → скрипт
