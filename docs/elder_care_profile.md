# Elder Care Profile — Aura для пожилых

Статус: draft v1
Дата: 2026-10-04
Автор: pythonvenom + AI

## Наука

- **Czaja & Lee, 2007**: упрощение интерфейса, не содержания
- **Ryan et al., 1995 (elderspeak)**: упрощённая речь снижает когнитивные показатели
- **Portet et al., 2013**: 3 свойства для elder care — устойчивость к ошибкам ASR, повтор, свои формулировки
- **Fisk et al., 2009**: явные индикаторы состояния
- **Czaja et al., 2018**: голосовые ассистенты и напоминания о лекарствах — доказанная эффективность

## Non-functional требования

| Требование | Значение | Почему |
|---|---|---|
| Латентность простых команд | < 1.5 с | пожилые теряют контекст на 3+ с |
| MIN_TURN_SILENCE | 1.8 с | пожилые делают длинные паузы в середине фразы |
| TTS speed | 0.9 | медленнее для восприятия |
| BargeIn | off | не перебивать |
| Confirm actions | on | «Хорошо, делаю» перед действием |
| Явные состояния | tick/«секунду» | не оставлять в тишине |

## Red team

- **Локация не указана**: спросить один раз, запомнить
- **Не расслышала 2 раза**: сменить тактику, не повторять
- **Не отвечать на вопрос вопросом**: elderspeak паттерн
- **Не спорить**: если батя сказал «5 градусов», а на улице 3 — не поправлять
