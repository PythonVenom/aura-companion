# FAQ — Часто задаваемые вопросы

## Общие

**Q: Что такое Аура?**

Голосовой ассистент для Linux. Работает локально, без облаков.

**Q: Сколько стоит?**

Бесплатно. Открытый код (MIT).

**Q: Кто делает?**

Один разработчик + ИИ-ассистент.

**Q: На каких ОС работает?**

- Arch Linux — production
- Ubuntu/Debian, Windows, macOS, Android — alpha

## Технические

**Q: Какой LLM?**

Ollama qwen2.5:7b Q4_K_M. 4.7 ГБ, работает offline.

**Q: Какой ASR/TTS?**

T-one (streaming, русский) + Piper (ru_RU-irina-medium).

**Q: Сколько RAM нужно?**

Минимум 4 ГБ. Рекомендую 8+ ГБ для комфортной работы LLM.

**Q: Работает без интернета?**

Да, после установки. Только погода требует сети.

**Q: Что с приватностью?**

Всё локально. Телеметрия отсутствует. См. docs/manual.md → Приватность.
