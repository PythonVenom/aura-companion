## Что такое Аура

Аура — голосовой помощник для компьютера. Работает полностью локально — данные никуда не уходят.

Отвечает голосом, выполняет команды: отвечает на вопросы, включает музыку, открывает вкладки, читает чаты, ведёт чек-лист.

Не требует интернета для базовых команд. LLM работает offline.

---

## Как включить

Аура запускается как системная служба.

Проверить статус:

    systemctl --user status aura.service

Должно быть active (running).

Запустить:

    systemctl --user start aura.service

Остановить:

    systemctl --user stop aura.service

Автозапуск при входе:

    systemctl --user enable aura.service

Логи:

    journalctl --user -u aura.service -f

## Как разговаривать

### 1. Активация

Скажи громко: **«Аура»**

Варианты (для устойчивости к ошибкам ASR):
- Аура
- Ара
- Ура
- Алло
- Аула

### 2. Пауза

После активации — пауза 1 секунда. Аура ждёт команду.

### 3. Команда

Чётко, не спеша: **«Который час»**

Или полной фразой: **«Аура, который час»**.

### 4. Ответ

Аура отвечает голосом через 1–2 секунды.

## Что умеет

### Голосовой цикл
- Слушает микрофон постоянно
- Активация по wake-word
- ASR T-one (RTF 0.058 — быстрее real-time)
- TTS Piper (300 мс)

### Понимание
- FSM — многошаговые диалоги
- Context — помнит, кто «она» после зачитки
- RAG — 570+ диалогов в ChromaDB

### Proactive (Аура говорит первой)
- Утренний брифинг
- Новое сообщение в Макс → «Зачитать?»
- Неотвеченные сообщения
- Напоминания о событиях

### Автоматизация
- Чек-лист голосом
- VK / Telegram / Макс — навигация
- Управление музыкой

## Что НЕ умеет

### Сейчас нет
- Barge-in (перебить Ауру голосом)
- Мобильные приложения
- Windows / macOS

### Понимает ограниченно
- Шум — фоновые разговоры путают ASR
- Быстрая речь — глотает окончания
- Сложные вопросы — LLM 7B не GPT-4

## Настройки

### Имя ассистента
По умолчанию: «Аура». Смена — в разработке.

### Голос
TTS: voices/ru_RU-irina-medium.onnx (женский).
Сменить: положить другую модель в voices/.

### Микрофон
Если Аура плохо слышит:

    alsamixer

Найди Capture → F4 → поднять до 100%.

## Проблемы и решения

### Аура не слышит

1. Проверь микрофон:

    arecord -d 3 /tmp/test.wav && aplay /tmp/test.wav

2. Если не слышишь себя — микрофон не работает
3. Если слышишь — подними уровень в alsamixer

### Аура молчит

1. Проверь логи:

    journalctl --user -u aura.service --since "1 minute ago"

2. Ищи ошибки (❌)
3. Проверь динамики: speaker-test -t sine -l 1

### Понимает неправильно

1. Говори медленнее
2. Чётче окончания
3. Ближе к микрофону
4. Меньше фонового шума

### Макс / Telegram / VK не работает

1. Открой Firefox
2. about:debugging#/runtime/this-firefox
3. Убедись что Aura Bridge загружен
4. Если нет — Remove → Load Temporary Add-on

## Приватность

### Что НЕ уходит наружу
- Голос (ASR локальный)
- Текст диалогов (LLM локальный)
- Данные чатов

### Что уходит
- Погода — open-meteo.com (без личных данных)
- Ollama модели — только скачивание

### Файлы состояния
- /tmp/aura_fsm.json
- /tmp/aura_calendar.json
- /tmp/aura_proactive.json
- ~/aura_private/ — приватные данные

Телеметрия отсутствует.

## FAQ

**Q: Можно на Windows?**
A: Пока нет, только Linux. Windows в планах на 2027.

**Q: Работает без интернета?**
A: Да, после установки. LLM, ASR, TTS локально.

**Q: Сколько ресурсов?**
A: ~4 ГБ RAM, 2 ядра. LLM ~48 tok/s на CPU.

**Q: Это безопасно?**
A: Да. Всё локально.

**Q: Можно сменить имя?**
A: Пока нет в UI. В разработке.

**Q: Как помочь?**
A: CONTRIBUTING.md. Баг-репорты, звёзды.
