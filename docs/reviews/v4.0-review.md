## 3. BUG-HUNT

За сессию v4.0:
1. `env -i` без XAUTHORITY (virt-manager)
2. `assert` в патчах — brittle
3. heredoc ломается на бэктиках (×3)
4. `!r` в python-строке ломает zsh
5. `_load_token` в bridge — old-блок не найден
6. ReActLoop потерян при перезаписи react_loop.py
7. `constitution.py` не создался (PYEOF обрыв)
8. ModuleNotFoundError в run_hallucination_eval (sys.path)

**Фиксы:** все закрыты (base64 для длинных файлов, write_text вместо heredoc, backward-compat тесты).
