## Легенда статусов

- ожидание — образ передан, ждём попытки
- в процессе — ставит / пробует
- работает — Aura отвечает, пользуется
- не работает — проблема, заводим баг
- отказ — не подошло

## Форма отзыва (для тестера)

1. Что получилось?
2. Что не получилось?
3. Какие баги нашёл?
4. Оценка работает/не работает: 1-5
5. Обратно поставил бы? да/нет

## Найденные баги -> GitHub Issues

Формат: [tester-N] короткое описание. Шаги воспроизведения.
