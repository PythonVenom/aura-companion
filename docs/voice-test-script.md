## Как пользоваться

1. Запусти сервис: `systemctl --user status aura`
2. Открой лог в отдельном терминале: `journalctl --user -u aura.service -f`
3. Читай по порядку → отмечай ✅ / ❌ в таблице
4. Финальный результат — в `docs/DEMO-CHECKLIST.md`

## Что критично

- **#9, #10, #11, #12, #13** — должны быть **молча** (ADR-048)
- **#34** — barge-in. Если не работает — ADR-009 (закомм.)
- **#14-#20** — не работают сейчас (Bug 23, 26)
- **#27** — не работает (Bug 27)

**После теста: список ❌ = план фиксов до видео.**
