# AURA для автоэлектрика

## Что это
Aura — голосовой ИИ-ассистент для диагностики авто.
Работает локально, без интернета.

## Как запустить

### Вариант А: Live-USB (проще)
1. Вставь флешку
2. Перезагрузи ноутбук
3. Зажми F12 (или Esc, F2, Del) при загрузке
4. Выбери USB
5. Aura загрузится автоматически

### Вариант Б: Windows
1. Открой PowerShell (от админа)
2. Запусти: `install_windows.ps1`
3. Aura установится в `C:\Aura`

## Как пользоваться

1. Подключи ELM327 (OBD-II адаптер) к машине и к ноутбуку (USB/Bluetooth)
2. Скажи: «Аура, прочитай ошибки»
3. Aura расшифрует коды (P0101, P0300 и т.д.)
4. Скажи: «Аура, что делать с P0300»
5. Aura объяснит: причины, что проверить

## Голосовые команды

- «Аура, прочитай ошибки»
- «Аура, расшифруй P0101»
- «Аура, сбрось ошибки»
- «Аура, покажи температуру двигателя»
- «Аура, покажи обороты»
- «Аура, что проверить при P0300»

## Что нужно купить

- ELM327 (OBD-II адаптер) — 500-1500 ₽
- Bluetooth или USB версия
